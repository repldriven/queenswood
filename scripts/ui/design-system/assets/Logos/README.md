The crowned forest as files, for where the `Logo` component cannot be used. Both carry their own colours (pine gradients over a gold crown) and are shown with `<img>`; neither takes a colour from CSS.

- `logo.svg` is Mark A: eight trees over a seven-tooth crown. The marketing site's mark and its favicon. Use it on `bone`, `paper`, `surface` or `surface-raised`.
- `favicon.svg` is Mark D: four trees over a five-tooth crown. The console's favicon, for small and narrow spaces.

Marks B, C and E exist only in the `Logo` component.
